Assignment 4: Loops & Flow Control

Three independent demonstrations: for loop multiplication table, while loop with break finding first number > 10 divisible by 6, and do...while loop with continue skipping selected elements.

Loop Logic Implementation 
// 1. For Loop: 5 Multiplication Table (1 to 5)
for (let i = 1; i <= 5; i++) {
  console.log(`5 x ${i} = ${5 * i}`);
}

// 2. While Loop: First number > 10 divisible by 6 with break
let num = 11;
while (true) {
  if (num % 6 === 0) {
    console.log(`Found: ${num}`);
    break;
  }
  num++;
}

// 3. Do...While Loop: Skip 3 using continue
let count = 0;
do {
  count++;
  if (count === 3) continue;
  console.log(`Remaining Number: ${count}`);
} while (count < 5);

Assignment 5: Functions & Scope

Demonstrates standard functions with default parameters, arrow function syntax, function vs block scope, and controlled catching of a ReferenceError.

Function & Scope Implementation 
// Standard function with default parameters (5 x 4)
function calculateStandardArea(length = 5, width = 4) {
  return length * width;
}

// Arrow function calculator
const calculateArrowArea = (length, width) => length * width;

// Controlled block scope test
try {
  {
    let blockVar = "scoped";
  }
  // Attempting access outside block throws ReferenceError
  console.log(blockVar);
} catch (err) {
  console.log(`Scope Test Error: ${err.name}: ${err.message}`);

Assignment 6: Arrays & Modern Array Methods

Processes product objects using forEach() for iteration, filter() for items under $50, and map() to generate uppercase tags.

Array Operations Code 
const products = [
  { name: "Laptop", price: 800 },
  { name: "Mouse", price: 25 },
  { name: "Keyboard", price: 45 }
];

// 1. forEach() listing
products.forEach(p => console.log(`Item: ${p.name} - Price: $${p.price}`));

// 2. filter() items < $50
const affordable = products.filter(p => p.price < 50);

// 3. map() formatted tags
const tags = products.map(p => `${p.name.toUpperCase()} costs $${p.price}`);
